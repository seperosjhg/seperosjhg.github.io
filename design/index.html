블로그 대문 구조

잘 나가는 블로그 대문, 6가지 구조

네이버 블로그 종합 상위 20곳(여행·육아·건강·어학·IT·반려동물)의 첫 화면을 직접 열어 보고 비슷한 모양끼리 묶었어요. 고객에게 보여 주면서 "어떤 모양이 마음에 드세요?"라고 고르게 하면 돼요.

17 / 20첫 화면을 프롤로그로 둠 (글 목록이 아니라 대문부터 보여 줌)
16 / 20대문에 직접 만든 사진·그림을 걸어 둠
15 / 20위 메뉴에 주제 2~4개를 걸어 바로 가게 함
9 / 20첫 화면에 인증 배지(인플루언서·이달의 블로그 등)를 보여 줌
1. 큰 사진 한 장형상위 20곳 중 6곳
대문 = 사진(그림) 한 장 + 블로그 이름. 들어오자마자 분위기가 보여요.
잘 맞는 고객
카페·꽃집·펜션처럼 사진이 강한 가게, 얼굴이 곧 브랜드인 강사·작가
들어가는 것
  • 가로 966px 큰 사진 위에 이름 한 줄
  • 그 아래 메뉴 한 줄(주제 2~4개)
  • 왼쪽 프로필 + 오른쪽 글 목록
네이버에서 만드는 법
꾸미기 설정 > 타이틀 꾸미기 > 직접 등록(가로 966, 세로 최대 600)
사진 위 글자는 크게 한 줄만. 휴대폰 첫 화면(커버)은 앱에서 따로 넣어야 해요.
2. 배경 + 아이콘 버튼형상위 20곳 중 2곳
꽉 찬 배경 사진에 한 줄 소개, 그 아래 동그란 버튼 3~5개.
잘 맞는 고객
예약·문의가 중요한 매장, 상담소, 학원, 여러 채널(인스타·유튜브)을 함께 하는 곳
들어가는 것
  • 넓은 배경 + 이름·한 줄 소개
  • 버튼: 메뉴 / 예약·문의 / 인스타 / 유튜브 / 지도
  • 버튼 아래 인증 배지·연락처
네이버에서 만드는 법
타이틀 직접 등록 + 위젯 직접등록(그림 170px + 링크)으로 버튼을 대문 바로 아래 한 줄로
조차장 블로그가 이 구조예요(아이콘 10개, 5개씩 2줄). 버튼 첫 칸은 "무료 상담"처럼 가장 원하는 행동.
3. 소개서(포트폴리오)형상위 20곳 중 1곳
대문 아래가 한 장짜리 회사 소개서처럼 정리돼 있어요.
잘 맞는 고객
강사·전문가·상담사, 복지관·기관, 협업 제안을 받고 싶은 사람
들어가는 것
  • 큰 대문 + 주제별 사진 칸 5개
  • 소개 / 대표 이력 / 활동 내역 / 채널 / 협업 문의 5칸
  • 마지막 칸에 문의 메일·폼 링크
네이버에서 만드는 법
1단 레이아웃 + 위젯 직접등록으로 사진 칸·글 칸을 만들기
숫자(경력, 수상, 순위)는 확인된 것만. 처음 오는 손님이 "누구인지" 10초 안에 알게 하는 게 목표.
4. 메뉴판 + 그림형상위 20곳 중 4곳
왼쪽엔 로고와 주제 목록(메뉴판), 오른쪽엔 캐릭터·사진 모음.
잘 맞는 고객
캐릭터·손글씨 로고가 있는 브랜드, 주제가 여러 개인 육아·생활 블로그, 공방
들어가는 것
  • 로고(손글씨·캐릭터) + 주제 목록 5~7줄
  • 오른쪽 대표 그림 1장 또는 사진 6칸 콜라주
  • 아래 SNS 아이콘 줄 + 검색창
네이버에서 만드는 법
대문 그림 안에 메뉴판을 그려 넣고, 실제 이동은 상단 메뉴·위젯 링크로
그림 안 글자는 눌러지지 않아요. 누를 곳은 꼭 위젯이나 메뉴로 따로 만들기.
5. 사진 바둑판형상위 20곳 중 4곳
대문은 작게, 그 아래 최신 글 사진이 4~5칸씩 줄줄이.
잘 맞는 고객
제품 리뷰, 맛집, 음식점 메뉴, 반려동물·육아 일상처럼 글마다 사진이 있는 곳
들어가는 것
  • 작은 대문(이름 + 사진 콜라주)
  • 메뉴 한 줄
  • 프롤로그: 이미지 강조형 4~5칸 × 여러 줄
네이버에서 만드는 법
프롤로그 설정 > 이미지 강조형, 메인에 보일 카테고리 고르기
대표 사진에 제목 글자를 크게 넣은 블로그가 눈에 잘 띄었어요. 사진 없는 글은 바둑판에 안 나와요.
6. 위젯 대시보드형상위 20곳 중 3곳
대문 그림 없이 프로필·카테고리·이웃 수·배지·방문자 그래프를 위에 한 줄.
잘 맞는 고객
글이 수천 편인 정보형 블로그, 숫자·배지가 곧 신뢰인 곳
들어가는 것
  • 위젯 한 줄: 프로필 / 카테고리 / 이웃 / 배지 / 방문 그래프
  • 바로 아래 글 목록
  • (변형) 3단: 양옆에 배너 위젯
네이버에서 만드는 법
레이아웃·위젯 설정에서 1단(위젯 위 줄) 또는 3단 선택
새로 시작하는 고객에겐 비추천. 숫자가 작으면 오히려 약해 보여요.
